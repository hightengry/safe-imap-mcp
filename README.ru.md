# safe-imap-mcp

**Даёт Claude (или любому ИИ-ассистенту с поддержкой MCP) читать и отправлять вашу почту по IMAP/SMTP, но не даёт ничего удалять.**

[English version](README.md)

Большинство почтовых интеграций для ИИ-ассистентов работают только с Gmail и Microsoft 365 или дают модели полный контроль над ящиком. `safe-imap-mcp` это небольшой локальный [MCP](https://modelcontextprotocol.io)-сервер для частого случая посередине: рабочие ящики у обычного хостинга (cPanel, Plesk, свой почтовый сервер), где ассистент должен искать, читать, готовить черновики и отправлять письма, но один неверный вызов не должен стереть ваши «Входящие».

- Работает с любым IMAP/SMTP-сервером и с несколькими ящиками одновременно.
- Запускается на вашем компьютере. Пароли его не покидают.
- **В коде нет операций удаления, перемещения и очистки писем.** Это проверяет автоматический тест.
- Чтение письма не отмечает его прочитанным.
- Вложения можно брать и сохранять только в разрешённых папках.

## Что может ассистент

| Инструмент | Что делает | Меняет что-то? |
|---|---|---|
| `list_accounts` | Список подключённых ящиков | Нет |
| `list_folders` | Папки ящика | Нет |
| `search_emails` | Поиск по отправителю, получателю, теме, тексту, датам, непрочитанным | Нет |
| `read_email` | Читает письмо целиком, показывает вложения | Нет (не отмечает прочитанным) |
| `list_attachment_folders` | Показывает разрешённые папки для вложений | Нет |
| `mark_as_read` | Ставит или снимает отметку «прочитано» | Только эту отметку |
| `save_attachments` | Сохраняет вложения письма в папку на компьютере | Создаёт новые файлы, не перезаписывает |
| `save_draft` | Сохраняет письмо в «Черновики» | Добавляет черновик |
| `send_email` | Отправляет письмо, в том числе ответом в той же переписке и с вложениями; кладёт копию в «Отправленные» | Отправляет письмо |

Инструментов для удаления, перемещения, архивации и очистки нет специально. Создавать и удалять ящики тоже нельзя.

## Что нужно

- [Node.js](https://nodejs.org) версии 18 или новее
- MCP-клиент: Claude Desktop, Claude Code или другой клиент с поддержкой локальных (stdio) MCP-серверов
- Доступ к ящику по IMAP и SMTP с паролем или паролем приложения

## Установка

### 1. Скачать

```bash
git clone https://github.com/hightengry/safe-imap-mcp.git
cd safe-imap-mcp
npm install
```

Или скачайте ZIP с GitHub, распакуйте и выполните `npm install` в папке.

### 2. Настроить ящики

```bash
cp accounts.example.json accounts.json      # Windows: copy accounts.example.json accounts.json
```

Отредактируйте `accounts.json`:

```json
{
  "defaults": {
    "imapHost": "mail.example.com",
    "imapPort": 993,
    "smtpHost": "mail.example.com",
    "smtpPort": 465
  },
  "accounts": [
    { "email": "you@example.com", "fromName": "Ваше Имя", "password": "ваш-пароль" },
    { "email": "info@example.com", "fromName": "Компания", "passwordEnv": "MAIL_PASSWORD_INFO" }
  ]
}
```

Имена серверов и порты обычно есть в панели хостинга в разделе вроде «Настройка почтового клиента» или «Ручная настройка».

Файл `accounts.json` внесён в `.gitignore` и не попадёт в репозиторий.

### 3. Проверить связь

```bash
npm run check
```

Команда входит в IMAP и SMTP каждого ящика и пишет `ok` или ошибку. Ничего не отправляет и ничего не меняет.

### 4. Подключить к ассистенту

**Claude Desktop.** Откройте *Settings → Developer → Edit Config* и добавьте сервер в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "email": {
      "command": "node",
      "args": ["C:\\path\\to\\safe-imap-mcp\\index.js"]
    }
  }
}
```

На macOS и Linux путь обычный, например `"/Users/you/safe-imap-mcp/index.js"`. Если раздел `mcpServers` в файле уже есть, добавьте в него только блок `"email": {...}`. Полностью закройте Claude Desktop и откройте снова.

Если Claude пишет, что не находит `node`, укажите полный путь, например `"C:\\Program Files\\nodejs\\node.exe"` или результат команды `which node`.

**Claude Code.**

```bash
claude mcp add email -- node /path/to/safe-imap-mcp/index.js
```

**Другие клиенты:** запускайте `node index.js` как stdio MCP-сервер.

### 5. Проверить

> Покажи 5 последних писем в ящике you@example.com.

## Настройки

| Ключ | Где | По умолчанию | Значение |
|---|---|---|---|
| `email` | ящик | обязательно | Адрес ящика, по нему выбирается ящик |
| `fromName` | ящик | нет | Имя отправителя в поле «От» |
| `password` | ящик | нет | Пароль или пароль приложения |
| `passwordEnv` | ящик | нет | Имя переменной окружения с паролем (вместо `password`) |
| `username` | ящик / defaults | `email` | Логин, если отличается от адреса |
| `imapHost`, `smtpHost` | ящик / defaults | обязательно | Имена серверов |
| `imapPort` | ящик / defaults | `993` | Порт IMAP |
| `smtpPort` | ящик / defaults | `465` | Порт SMTP (`587` использует STARTTLS) |
| `imapSecure`, `smtpSecure` | ящик / defaults | по порту | Принудительно включить или выключить TLS |
| `attachmentFolders` | верхний уровень | Рабочий стол, Документы, Загрузки (и варианты OneDrive) | Откуда можно прикладывать файлы и куда сохранять вложения |
| `limits.maxRecipients` | верхний уровень | `20` | Максимум адресатов (to + cc + bcc) в письме |
| `limits.maxAttachments` | верхний уровень | `10` | Максимум вложений в письме |
| `limits.maxAttachmentMB` | верхний уровень | `20` | Максимальный общий размер вложений |

Файл настроек перечитывается при каждом вызове, поэтому пароли и лимиты можно менять без перезапуска. Чтобы хранить настройки в другом месте, задайте переменную `MAIL_ACCOUNTS_FILE=/путь/к/accounts.json` (в Claude Desktop это делается блоком `"env"` рядом с `"args"`).

## Как устроена безопасность

Цель: запутавшийся, ошибившийся или обманутый ассистент в худшем случае отправит письмо, которое вы одобрили, но никогда не уничтожит данные.

1. **Нет разрушительных операций.** В коде нет вызовов удаления, перемещения, копирования, очистки и переименования писем и папок, и никогда не ставится IMAP-отметка `\Deleted`. Если такое появится, `npm test` упадёт. Все инструменты помечены `destructiveHint: false`.
2. **Чтение без последствий.** Для поиска и чтения ящик открывается только на чтение.
3. **Отправка с одобрения человека.** Описание `send_email` требует от ассистента показать отправителя, адресатов, тему, полный текст и пути к вложениям и дождаться вашего явного согласия. В Claude Desktop на запрос разрешения для `send_email` отвечайте **Allow once (Разрешить один раз)**, а не «Всегда», тогда каждую отправку нужно подтверждать кнопкой.
4. **Защита от подсказок в письмах.** Входящие письма считаются недоверенными. Инструменты велят ассистенту воспринимать текст писем как данные и не прикладывать файлы и не добавлять адресатов только потому, что об этом просит письмо.
5. **Песочница для вложений.** Файлы можно брать только из `attachmentFolders`. Ссылки (symlink) сначала раскрываются, обход через `..` отклоняется, папка программы, файл настроек и журнал отправок закрыты всегда, файлы с именем вида `accounts*.json` не прикладываются. Сохранённые вложения получают безопасные имена, не перезаписывают существующие файлы и не открываются.
6. **Лимиты.** Число адресатов, число и общий размер вложений ограничены, массовые рассылки невозможны.
7. **Журнал.** Каждое отправленное письмо записывается в `sent-log.txt` рядом с файлом настроек: время, отправитель, адресаты, тема, вложения.

### От чего это не защищает

- **Пароли на диске.** `accounts.json` хранит пароли открытым текстом, если не использовать `passwordEnv`. Их может прочитать любой, у кого есть доступ к вашей учётной записи на компьютере. Используйте пароли приложений, если провайдер их поддерживает, и не передавайте файл.
- **Одобрение неудачного письма.** Если вы одобрили письмо, оно уйдёт. Читайте, что одобряете.
- **Функции самого почтового сервиса.** Серверные фильтры, правила пересылки и веб-почта вне зоны действия инструмента.

Как сообщить об уязвимости: [SECURITY.md](SECURITY.md).

## Совместимость

- **Почта на хостинге (Plesk, cPanel, DirectAdmin, Dovecot/Postfix):** основной сценарий, вход по паролю.
- **Gmail / Google Workspace:** работает с `imap.gmail.com` / `smtp.gmail.com` и паролем приложения, если аккаунт или администратор ещё разрешают пароли приложений. Gmail сам сохраняет отправленные письма, поэтому в «Отправленных» может появиться две копии.
- **Microsoft 365 / Outlook.com:** требуют OAuth для IMAP/SMTP, этот инструмент его не поддерживает. Используйте официальный коннектор Microsoft 365 вашего ассистента.
- Письма отправляются обычным текстом, без HTML-оформления.
